# Diagramas da Arquitetura

Este diretório separa os diagramas-fonte em PlantUML das imagens exportadas.

## Estrutura

- `plantuml/`: arquivos-fonte editáveis (`.puml`)
- `imagens/`: exportações renderizadas (`.png`)

## Diagramas disponíveis

- Arquitetura geral
- Diagrama de atividades
- Diagrama de classes
- Diagrama de componentes
- Diagrama de sequência
